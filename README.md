# BestBudd.com

**A full-stack LMS style web application targeted for special-needs students in life-skills classrooms**

---

## 🚀 Overview

BestBudd.com is a web application built with **Node.js**, **SQLite**, **EJS**, and modern **HTML/CSS/JavaScript**. It empowers special-needs students in life-skills classrooms by offering personalized dashboards, reminders, schedules, and daily reflection tools. Teachers gain real-time insights and easy management capabilities—helping bridge the gap that generic platforms like Google Classroom leave behind.

---

## 🎯 Key Features

### Student Dashboard
- **Daily Reminders**: Customizable check-ins (“Today I will…”).  
- **Phonebook**: Quick access to important contacts.  
- **Bookmarks**: Save and categorize helpful websites.  
- **Schedule**: View and manage daily or weekly tasks.  
- **Reflection Report**: Prompted journaling to document progress and feelings.

### Teacher Dashboard
- **Class-Wide Announcements**: Post reminders visible to all students.  
- **Student Monitoring**: Drill into each student’s dashboard to review activity logs and reflection entries.  
- **Targeted Support**: Add private notes and follow-up tasks per student.  
- **Roster Management**: Create, edit, or remove student profiles.

## 🛠️ Tech Stack

- **Runtime**: Node.js

- **Styling**: Custom CSS with responsive layouts
